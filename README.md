# Terraform AWS Infrastructure Setup (Minor Project)

Provisions AWS infrastructure with Terraform in `ap-southeast-2` (Sydney):

- VPC (10.0.0.0/16)
- Public subnet (10.0.1.0/24)
- Internet gateway and route table
- Security group allowing SSH only from my IP
- Key pair generated by Terraform (tls provider)
- EC2 instance (Amazon Linux 2023)

## Usage

1. Configure AWS credentials: `aws configure`
2. Create `terraform.tfvars` with: `my_ip_cidr = "YOUR.IP.ADDRESS/32"`
3. Run:

        terraform init
        terraform plan
        terraform apply

4. Connect: `ssh -i minor-project-key.pem ec2-user@<public_ip>`
5. Clean up: `terraform destroy`
